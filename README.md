# 🚗 RentalCar — MS Tour & Travels

A modern, responsive and professional **car rental and outstation travel website** built for **MS Tour & Travels**. The website provides users with information about rental services, popular travel routes, vehicle options, pricing, and booking enquiries.

🌐 **Live Website:** https://apk374625-cloud.github.io/RentalCar/

---

## 📌 About the Project

**RentalCar** is a frontend web development project designed to create a realistic online presence for a premium chauffeur-driven car rental business.

The website focuses on providing a clean, modern and user-friendly experience for customers looking for:

* 🚘 Car rentals
* 🏔️ Outstation trips
* ✈️ Airport transfers
* 👨‍👩‍👧‍👦 Family holiday tours
* 💼 Corporate transportation
* 💍 Wedding car rentals
* 📍 Local Chandigarh travel

The website is designed around **MS Tour & Travels**, offering travel services from Chandigarh to destinations across North India.

## 💻 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ApekshaTheDeveloper/RentalCar.git
```

### 2. Open the project

```bash
cd RentalCar
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the website

Open `index.html` directly in your browser or use the **Live Server** extension in VS Code.

## 📤 Deployment

This project is deployed using **GitHub Pages**.

Every time changes are pushed to the configured GitHub branch, the website can be updated through GitHub Pages.

---

## 🔄 Updating the Project

After making changes in VS Code:

```bash
git add .
git commit -m "Update website"
git push
```

GitHub Pages will then deploy the updated version.
